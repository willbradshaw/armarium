# D&D 5.5: levels gained

This addendum, from the `dnd-5-5` extension, carries a Session's levels into
the characters' records.

In step 1, read the Session's `### Advancement` section under Rewards, if it
has one. Each character it names belongs under "appeared", even if the Notes
link them nowhere else. In step 2, set that character's `level` to the level
the section gives, along with any other change the Session makes to them.
