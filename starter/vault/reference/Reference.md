# Reference

Keep game rules, bibliographic/source notes, and other external reference material
here. Record source and provenance when adding material. These pages describe
reference information; they do not establish that an event happened in a campaign.

Use `sources/` for source records. Store maps and handouts to embed in [[assets/Assets]].
Incoming originals belong in `.input/unprocessed/` until reviewed.
