# Live views

This basic starter uses ordinary links and manually maintained indexes. Automated
clue views and session-preparation tables will be added after the Bases prototype
is evaluated. Neither Dataview nor untested Base queries are required to use it.

Keep each clue's text on its clue page and each entity's summary on its entity page.
Link to those pages from preparation and Active Clues; avoid maintaining parallel
copies of their text. See [[Vault Guide]] for preparation-selection properties.
