# Example extension

Locations use the structure in [[types/Content]] and require a `climate` field:
a nonblank description, or null when unrecorded. The Location template leaves it
null for you to fill in. The field applies to shared and campaign Locations.

See the [schema](schemas/extensions/example/location.schema.json) and
[template](templates/extensions/example/Location.md).
